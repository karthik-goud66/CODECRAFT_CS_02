# 🔐 Pixel Manipulation for Image Encryption

## 📌 Project Overview
This project implements a simple image encryption and decryption tool using Python and pixel manipulation. It encrypts an image by modifying its pixel values using a mathematical operation and decrypts it using the reverse operation.

This project was developed as part of **Task 02 – Cyber Security Internship at CodeCraft Infotech**.

## 🎯 Objectives
- Understand image encryption using pixel manipulation.
- Apply mathematical operations to image pixel values.
- Encrypt and decrypt images using a secret key.
- Learn basic concepts of data confidentiality and information security.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **Library:** Pillow (PIL)
- **Concept:** Pixel Manipulation

## ⚙️ Features
- Encrypt images using pixel value manipulation.
- Decrypt encrypted images using the same key.
- Support common image formats such as PNG and JPEG.
- Simple and beginner-friendly implementation.

## 📥 Installation

1. Install Python 3 on your computer.
2. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Pixel-Manipulation-Image-Encryption.git
   ```

3. Open the project folder:

   ```bash
   cd Pixel-Manipulation-Image-Encryption
   ```

4. Install the required library:

   ```bash
   pip install -r requirements.txt
   ```

## ▶️ How to Run

Run the Python program using:

```bash
python image_encryption.py
```

Follow the instructions displayed by the program to select an image and perform encryption or decryption.

## 🔑 How It Works

1. The program loads the input image.
2. It reads the pixel values of the image.
3. A mathematical operation is applied to encrypt the pixel values.
4. The encrypted image is saved as a new file.
5. The reverse operation restores the original pixel values during decryption.

**Note:** The exact encryption and decryption steps depend on the implementation in `image_encryption.py`.
